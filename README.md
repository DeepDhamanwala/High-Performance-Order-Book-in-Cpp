# High-Performance-Order-Book-in-C-
A low-latency, thread-safe limit order book and matching engine implemented in modern C++, designed to simulate core components of real-world trading and payment systems.
Overview

A price–time priority limit order book capable of handling high-frequency order flows with low latency.

System supports:

Order insertion, matching, cancellation, and modification

Deterministic price–time priority matching

Thread-safe concurrent order processing


🔹 Features

✅ Limit order book (Buy & Sell sides)

✅ Price–time priority matching

✅ Partial and full order fills

✅ Order cancellation

✅ Order modification

✅ Thread-safe operations

✅ Deterministic matching behavior

✅ Low-latency design (cache-friendly data structures)


🔹 Supported Order Types

Limit Buy

Limit Sell
